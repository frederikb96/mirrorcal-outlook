MirrorCal Outlook

Mirrors your Outlook web calendar one-way into a CalDAV calendar. Nothing is ever written to Outlook. The destination calendar is overwritten; only events carrying this mirror's owner marker are changed or removed.

    Calendar server

    The password is stored unencrypted in this browser profile's extension storage. Use an app password, which can be revoked; it still gives access to the whole account, not just this calendar. It is only ever sent to the server it was entered for.

    Marks the events this mirror owns. Keep it identical on every browser that mirrors the same calendar, and give those browsers identical filters and policies; otherwise they keep rewriting each other's events. Changing it later leaves the events of the old id behind.

    Private events

    Events Outlook marks private, personal or confidential are always written with a private flag. Unless they are copied, only the replacement title is kept. Time, all-day flag and availability are always mirrored. Copying descriptions reads every event body on each sync.
